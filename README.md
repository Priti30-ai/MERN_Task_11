# Thala-7 Sneaker Store

Thala-7 is a simple sneaker store website created using HTML, CSS and JavaScript.

The website has four pages:

- Home page
- Product page
- Shopping Cart page
- Payment page

## Pages

### Home

The home page contains the store name, a short introduction and some basic store information.

### Product

The product page shows the sneaker details, price, product images, quantity buttons and Add to Cart button.

### Cart

The cart page shows the products added to the cart.

Users can:

- Increase product quantity
- Decrease product quantity
- Remove products from the cart
- Apply coupon codes

The cart also calculates:

- Sub Total
- Tax
- Discount
- Total Amount

### Payment

The payment page contains a simple payment form and displays the order summary before payment.

## Main Features

- Product image gallery
- Quantity selection
- Add to Cart
- Remove product from cart
- Change cart quantity
- Cart data saved using localStorage
- Coupon code functionality
- Automatic total calculation
- Payment form
- Order summary
- Responsive design for mobile and tablet devices

## Coupon Codes

The following coupon codes can be used:

- `THALA7` - 10% discount
- `WELCOME10` - ₹200 fixed discount
- `SEVEN50` - 15% discount

Coupon codes are not case-sensitive.

Some coupons have a minimum purchase amount before they can be applied.

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser localStorage
